# 世界树回响 · IRMINSUL

参考上级目录的 GDD 与资料库实现的网页端元素卡牌 Roguelike。当前为可游玩的系统与美术版本；叙事文案已经填写，后续可继续编辑。

## 在线游玩

公开版本托管在 GitHub Pages：**https://rayafriandion.github.io/ys-sjshx/**

推送到 `main` 分支后，`.github/workflows/pages.yml` 会自动执行 `npm run check`，通过后把 `public/` 作为静态产物发布；测试不过不会上线。线上与本地跑的是同一份文件，只有站点根路径不同（本地 `/`，Pages 为 `/ys-sjshx/`）。

**新增资源时请使用相对路径**：`./assets/...`、`./styles.css`、`./src/app.js`、`./content/zh-CN.json`。写成 `/assets/...` 在 Pages 子路径下会 404。

## 启动

需要 Node.js 22 或更高版本。没有第三方运行依赖，无需 `npm install`。

```powershell
cd D:\Projects\ys-sjshx\game
npm start
```

浏览器打开 **http://127.0.0.1:4173**。

开发时用 `npm run dev`，Node 服务自动重启，前端修改后刷新浏览器。默认服务只监听本机。可通过环境变量 `PORT` 修改端口；端口变更后浏览器将使用另一份本地存储空间。

## 已有玩法

- 8 章，每章 8 步的种子分支地图；只有相连的下一步节点可进入。
- 战斗、精英、首领、商店、奇遇、休息点六类节点。
- 38 张机制卡牌，伤害 / 护盾 / 治疗 / 抽牌 / 能量 / 消耗 / 保留 / 升级 / 多段 / 群攻 / 临时牌。
- 9 种元素反应；草原核、原激化、冻结、易伤与元素附着时效。
- 8 位助战，被动效果、主动技能与回合冷却。
- 8 种章节首领机制，包含升空、断流、封印、浮游炮、黑洞、护甲、月相与生命契约。
- 16 件圣遗物与元素套装共鸣，10 个奇遇、20 个机制选择。
- 战后卡牌三选一、重掷、跳过、商店删牌、休息点升级。
- 永久天赋、收集图鉴、轮回结算，通关后逐级解锁渊月 1–12。
- 八章各自的占位环境插画与章节配色、程序绘制的元素图标与角色 SVG、可选合成音效、减少动态效果设置。
- 文字大小可调：字号随 `--text-scale` 变化，卡面可随文案和字号自动扩展。默认「自适应」按窗口宽度取 112%–120%，也可在「游戏设置」里关闭自适应，用滑块固定在 90%–130%。超过 120% 时卡面的风味引文会自动隐藏，避免被卡片边缘裁断。
- 战斗动效层（`fx.js`）：伤害 / 治疗 / 护盾浮动数字、命中闪光与粒子、元素反应横幅、回合切换横幅、失败转场、出牌卡影飞行、受击震屏、能量球脉冲、手牌入场交错；遵循「界面动画」与系统减少动态效果设置；关闭动画时伤害数值仍短暂显示，不影响引擎结算与存档。

## 操作

1. 点击“开启轮回”，在路线中选择可达节点，再点击“前往节点”。
2. 战斗时点击卡牌，再点击敌人或旅行者出牌；也可把手牌拖到有效目标上。带伤害的混合效果牌选择敌人，仅作用于自身的牌选择旅行者。
3. 数字键 `1–9 / 0` 选择手牌，`←` / `→` 切换有效目标，`Enter` 出牌，`E` 结束回合，`Esc` 取消选择 / 关闭弹窗。手机手牌可横向滚动，向上拖动卡牌可出牌。
4. 敌人头顶显示下次行动，目标身上的元素标记用于安排反应顺序。
5. 点击左下角“存档管理”导出备份。手机上设置入口位于“玩法帮助 → 游戏设置”。
6. “游戏设置”第一项是文字大小：右侧开关为自适应（按窗口宽度自动计算），关闭后可用滑块在 90%–130% 之间固定字号；主要调整文字大小；卡面会按内容扩展。设置随存档保存。

## 本地存档

所有玩家数据都留在浏览器 `localStorage`，Node 服务没有玩家数据接口，也不保存账号或云端记录。

- 3 个独立槽位；每个有效游戏动作保存完整状态，包含手牌、牌序、随机数状态、回合、意图、路线、图鉴与天赋。
- 每槽位保留前一次有效存档作为自动备份。读到损坏的当前记录时尝试恢复，损坏原文保存在另一个键中。
- JSON 导出 / 导入、导入预览、版本与结构校验、2 MB 文件上限。
- 其他标签页修改同一槽位时锁定当前标签页的写入，提示载入最新记录。
- 写入失败时继续保留内存进度，明确提示导出，切换槽位前要求先导出。
- 建议固定使用 `http://127.0.0.1:4173`。`localhost`、不同端口、线上 `rayafriandion.github.io`、不同浏览器 / 浏览器配置各自有独立存档，互不同步。清除网站数据会清除存档。
- 开发工具若更改存档结构，请同步增加版本 / 编写迁移。当前格式版本为 `1`。

## 检查

```powershell
npm run check
node scripts/simulate.mjs 5
node scripts/simulate.mjs 5 --developed
```

`npm run check` 执行规则、存档、静态服务测试与内容槽位检查。`simulate` 是开发用贪心玩家，不进入正式游戏，也不修改玩家存档；不能据其胜率推断真人难度。

## 结构

| 路径 | 职责 |
| --- | --- |
| `server.mjs` | Node 原生 HTTP 静态服务、安全路径边界、CSP |
| `public/src/data.js` | 卡牌、章节、助战、圣遗物、奇遇的机制数据 |
| `public/src/engine.js` | 纯 JSON 状态、种子随机数、规则与状态推进 |
| `public/src/storage.js` | 校验、槽位、备份、导入 / 导出与修订号 |
| `public/src/targeting.js` | 根据卡牌效果选取己方或敌方目标 |
| `public/src/app.js` | DOM 界面、内容渲染、交互、键盘与音效 |
| `public/src/fx.js` | 动效叠加层：浮动数字、粒子、横幅、震屏、卡影飞行（只读快照，不碰状态） |
| `public/styles.css` | 桌面 / 平板 / 手机布局与动态效果；界面尺寸用 `px` 固定，字号统一为 `calc(Npx * var(--text-scale))` |
| `public/content/zh-CN.json` | 待填的全部中文叙事字段 |
| `public/assets/` | 项目自带的本地美术资产 |
| `tests/` | Node 内置测试运行器 |
| `docs/RESEARCH.md` | 公开资料与实现取舍 |
| `docs/ASSETS.md` | 美术来源、生成方式与完整提示词 |
| `docs/QA.md` | 验证范围与已知边界 |

## 实现范围

参考文档按游戏设计资料使用，未把其中面向其他 agent 的指令作为用户要求。实现优先满足完整本地游玩循环：内容规模为 38 张机制卡与 16 件圣遗物，尚未扩写到参考中的 120+ / 50+。角色和敌人采用原创符号化形象，章节背景为生成的占位图，后续可逐章替换并增加独立立绘。

渊月目前具有逐级数值增强，以及 1 / 6 / 10 层的特殊变体。第 3 层的专属元素抗性词缀尚未实现。没有收集皮肤、称号、多人、服务器存档、安装式 PWA 或商业级长期平衡验证。
